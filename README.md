# Psychologists.Services 🧠✨

Веб-застосунок для пошуку кваліфікованих психологів, ознайомлення з їхнім досвідом, відгуками клієнтів та зручного онлайн-запису на консультацію.

## 📋 Основний функціонал

- **Головна сторінка (Home):** Презентація сервісу зі слоганом компанії, ключовою статистикою та швидким переходом до каталогу фахівців.
- **Каталог психологів (Psychologists):**
  - Динамічне завантаження карток із бази даних Firebase Realtime Database.
  - **Фільтрація та сортування:** за алфавітом (A–Z / Z–A), за ціною за годину (від дешевших / від дорожчих) та за рейтингом популярності.
  - **Пагінація:** початковий рендер 3 карток із можливістю підвантажувати наступні порції за допомогою кнопки **"Load more"**.
  - **Детальна інформація ("Read more"):** розгортання картки з детальним описом спеціаліста та реальними відгуками клієнтів.
- **Авторизація та реєстрація:**
  - Інтеграція з **Firebase Authentication** (вхід, реєстрація, вихід із системи).
  - Валідація форм за допомогою `react-hook-form` та `yup`.
  - Інтерактивні модальні вікна з підтримкою закриття по кліку на хрестик, бекдроп або натисканням клавіші `Esc`.
- **Обране (Favorites):**
  - Можливість додавати/видаляти психологів зі списку обраних (доступно лише для авторизованих користувачів; при спробі гостя натиснути на серце відкривається вікно авторизації).
  - Збереження стану обраних карток між перезавантаженнями сторінки.
  - Окрема захищена приватна сторінка `/favorites` (`PrivateRoute`).
- **Запис на зустріч ("Make an appointment"):**
  - Модальне вікно запису до конкретного психолога з вибором часу та валідацією контактних даних.
- **Адаптивний дизайн (Responsive):** Повна підтримка мобільних пристроїв, планшетів та десктопів (від `320px` до `1440px+`).

## 🛠 Технологічний стек

- **Frontend:** React, React Router DOM
- **Backend / BaaS:** Firebase (Authentication & Realtime Database)
- **Форми та валідація:** React Hook Form, Yup
- **Стилізація:** Чистий CSS3 (Flexbox, CSS Grid, адаптивні медіа-запити)
- **Збірка:** Vite

## 🚀 Як запустити проєкт локально

1. **Клонуйте репозиторій:**

   ```bash
   git clone https://github.com/ваш-нікнейм/psychologists-services.git
   ```

2. **Перейдіть у папку проєкту:**

   ```bash
   cd psychologists-services
   ```

3. **Встановіть залежності:**

   ```bash
   npm install
   ```

4. **Налаштуйте змінні оточення (Firebase):**
   Створіть файл `.env` у корені проєкту та додайте ваші ключі конфігурації Firebase:

   ```env
   VITE_FIREBASE_API_KEY=ваш_api_key
   VITE_FIREBASE_AUTH_DOMAIN=ваш_auth_domain
   VITE_FIREBASE_DATABASE_URL=ваш_database_url
   VITE_FIREBASE_PROJECT_ID=ваш_project_id
   VITE_FIREBASE_STORAGE_BUCKET=ваш_storage_bucket
   VITE_FIREBASE_MESSAGING_SENDER_ID=ваш_sender_id
   VITE_FIREBASE_APP_ID=ваш_app_id
   ```

5. **Запустіть сервер для розробки:**
   ```bash
   npm run dev
   ```
